## 📖 О проекте

DevilsAdvocateAI — это интеллектуальный инструмент, который помогает взглянуть на ваши идеи, планы или аргументы с противоположной точки зрения. Он выступает в роли критика, выявляя слабые места, возможные риски и контраргументы, которые вы могли упустить.

## ✨ Ключевые особенности

- **Критический анализ:** предоставляет контраргументы и указывает на слабые места в идеях.
- **Выявление рисков:** помогает предвидеть потенциальные проблемы и негативные последствия.
- **Генерация альтернатив:** предлагает другие точки зрения и подходы к решению задачи.
- **Простой интерфейс:** лёгкий в использовании веб-интерфейс.

## 🛠️ Технологический стек

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **AI:** Интеграция с внешним AI API (настраивается через `.env`)

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KerwekNess/DevilsAdvocateAI.git
   cd DevilsAdvocateAI
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Настройте переменные окружения:**
   - Скопируйте файл `.env.example` в `.env`.
   - Впишите в `.env` ваш API-ключ и другие настройки.
4. **Запустите приложение:**
   ```bash
   python app.py
   ```
